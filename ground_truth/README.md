# Private ground-truth handoff

The committed folder contains no real answer key. Place Dataset & Ground Truth Management's original, independently prepared files in
`ground_truth/private/` (ignored by Git): `S01_ground_truth.csv`, `S02_ground_truth.csv`, and
`S03_ground_truth.csv`. Alternatively pass their actual directory with `--ground-truth`.

Required CSV columns: `scenario_id,stage_id,stage_order,time_utc,expected_label,security_record_ids,sysmon_record_ids`.
Stage IDs must be unique within a scenario; order must be contiguous from 1. Labels are `malicious` or
`benign`; source record IDs must be positive original EventRecordIDs, separated by semicolons. Optional
`mitre_technique` accepts a semicolon-separated list. Every cited record must resolve in the evaluated corpus.

Owner-designated contextual exclusions go in `scoring_exclusions.json` with schema
`scoring-exclusions-v1` and `neutral_evidence_ids` mapping each scenario to its original scoped evidence IDs.
No exclusions file means no owner-designated exclusions. The approved contract and independent reviews bind
the exact CSV and exclusions bytes. Changing them requires fresh review.

Keep Dataset & Ground Truth Management's private runbooks under `runbooks/private/`. Investigators and verifier must never read these
materials. Only post-run evaluation reads the answer key. Do not derive a replacement key from detections,
model claims, or verifier verdicts. Blank review forms are generated by
`python -m evidence_verification.evaluation.prepare_review` after all runs exist.
